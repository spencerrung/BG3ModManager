================================================================================
KEY ARCHITECTURAL CHANGES
================================================================================

BEFORE (WPF - Windows Only):
    GUI (WPF)
        ↓
    Core (With Windows P/Invoke code)
        ↓
    Windows-Specific Services

AFTER (Avalonia - Cross-Platform):
    GUI.Avalonia (Works on Windows + Linux + macOS)
        ↓
    Core (Pure C#, no platform-specific code)
        ↓
    Platform Abstraction Layer
        ├─ Windows Implementation (P/Invoke, Registry)
        └─ Linux Implementation (System calls, File-based config)

BENEFIT: Single codebase, multiple platforms
